# Where the record usually lives

Starting points for step 3. Always confirm that the page is the owner's own and read its date.
An aggregator (a site that collects versions, prices or schedules from many vendors) is a good
map and a weak source: use it to find the owner's page, then cite the owner.

| Topic | Primary record | Watch for |
| :--- | :--- | :--- |
| Software release, support or end of life | The project's own release or support schedule page, its changelog, its release tags | A status column that lags the dates beside it; "scheduled" dates that moved; distro packages that lag upstream |
| Package versions | The package registry page (PyPI, npm, crates.io and the like) and the project's tags | A docs site pinned to an old version; a pre-release shown as latest |
| Whether a feature shipped | Release notes or changelog, then the code or docs for that version | An issue or feature request still open after it shipped; a roadmap read as a release |
| Behaviour of a tool on this machine | Running it on a throwaway file in a scratch folder, with the version printed | The docs for a different platform or version (GNU and BSD tools differ) |
| APIs and cloud services | The provider's own reference docs and its changelog or deprecation page | Region-specific limits; old blog posts that still rank well |
| Prices and plans | The vendor's pricing page, read today, with region, currency and tax noted | Cached or third-party price lists; introductory offers shown as the price |
| Standards and specifications | The standards body's published text, with its version or date | Drafts cited as final; summaries that drop the conditions |
| Laws, rules and official guidance | The official register, legislature or regulator for that place | Rules that differ by country or state; a bill reported as passed; repealed text |
| Companies and organisations | The organisation's own site, official filings or registers | Acquisitions and renames; staff pages that lag |
| People and roles | The organisation's own page about the role, or an official register | News that predates a change |
| Science and health | The paper itself, a systematic review, or a national health body's guidance | Press releases that overstate; preprints read as settled; one study read as consensus |
| Statistics | The agency that produces the series, with the period it covers | A figure quoted without its year; revised series |
| Opinion and experience | Forums and reviews from several independent users, newest first | Affiliate "best of" lists; one thread treated as the community |

If none of these fits, ask: who would be embarrassed if this were wrong? Their own page is usually
the record.
