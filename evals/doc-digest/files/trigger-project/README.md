# Committee papers (DEMO)

DEMO folder for the doc-digest trigger tests. Everything here is invented.

This folder holds the documents the allotment committee works from:

- `handbook.pdf`: the plot-holder handbook, 24 pages.
- `board-update.pptx`: a food bank board update a committee member brought for comparison.
- `expenses-policy.docx`: a rowing club's expenses policy, used as a model for ours.
- `notes.md`: notes from the last committee meeting.
- `minutes/`: past minutes, one file per meeting.
