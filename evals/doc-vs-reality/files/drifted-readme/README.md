# tidy-notes

Small helper scripts for tidying a notes folder. All three scripts are tested.

## Install

Run `npm install`, then copy the three scripts in `scripts/` onto your PATH.

## Scripts

- `scripts/dedupe.sh` removes duplicate notes
- `scripts/rename.sh` renames notes by date
- `scripts/archive.sh` moves old notes to `archive/`

Requires Python 3.11 (see `pyproject.toml`).
