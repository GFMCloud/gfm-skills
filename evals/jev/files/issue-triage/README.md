# issue-triage

Triage for the public issue tracker of `tidyplot`, an open-source plotting library (demo project).
Every issue is public. `triage.py` labels each new issue `bug`, `feature`, `question` or `docs` with
keyword rules; a maintainer corrects the label by hand. About 40 issues a week; the keyword rules are
wrong often enough that maintainers re-label roughly one in three.

Past issues with the label a maintainer settled on are in `data/issues_labelled.jsonl`.
