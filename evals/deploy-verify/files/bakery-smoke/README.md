# Crumb & Co bakery website (DEMO)

DEMO project for a skill trial; not a real business. The site's files are in `site/`. It is
deployed by copying `site/` to the host.

- The current release (42) is running at http://127.0.0.1:{{SITE_PORT}}/ (a demo server on this
  machine).
- The previous release (41) is still up at http://127.0.0.1:{{PREV_PORT}}/ until the host's next
  clean-up.
