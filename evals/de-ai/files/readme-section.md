## Getting started

Getting started with tidyfeed is a seamless experience that empowers you to take control of your feeds. Simply install it and you're ready to go — it's that easy.

```sh
pip install tidyfeed
tidyfeed fetch --all --robust-retries
```

As one early user put it: "It's not just a feed reader, it's a game-changer."

tidyfeed stores everything in `~/.tidyfeed/feeds.db`. It needs Python 3.10 or later.
