# Pantry Pal

> DEMO PROJECT for the gfm-skills `brag` evals. Made up; not a real product.

Pantry Pal finds recipes you can cook with what is already in your cupboard.

## How it works

1. Type what is in your pantry, or tap the items you always keep.
2. Tap **Find recipes**.
3. Get recipes ranked by how few things you would need to buy. Most nights it is zero.

## Features

- Matches against 2,400 tested recipes.
- "Missing one thing?" swaps: it suggests a substitute you already have.
- Works offline once loaded.

## Run it

Open `index.html` for the landing page and `src/routes/results.jsx` for the app.
