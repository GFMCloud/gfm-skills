# New wiki page format (demo material)

Each old page in docs-old/ becomes docs-new/<same name>.md:

```
---
title: <the old page's first line, in sentence case>
updated: <the "last edited" date as YYYY-MM-DD; the old dates are day/month/year>
---

<the body, unchanged>
```

A page whose "last edited" line is missing or unreadable is not converted; list it for the shop manager.
