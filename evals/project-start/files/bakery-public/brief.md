# Brief (demo material for a skill trial)

A new website for Crumb and Co, a made-up bakery: one hand-written HTML page with opening hours,
the menu and a map link. No build step, no framework. It will be hosted on GitHub Pages, so the
repo is public, under the MIT licence. Owner on GitHub: whoever is signed in to gh.
Never put the owners' home address or phone number on the site.
