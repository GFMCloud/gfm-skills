ROW_NUMBER and partitions

By the end you can explain what PARTITION BY does in the top-customers query.

It is the part of the copied query you could not explain.

The idea

A window function computes a value for each row from a set of related rows, without collapsing them (PostgreSQL docs, 3.5). PARTITION BY splits the rows into groups; the numbering restarts in each.

Worked example

ROW_NUMBER() OVER (PARTITION BY region ORDER BY total_sales DESC)

Numbers customers 1, 2, 3 within each region, biggest first.

Practice
